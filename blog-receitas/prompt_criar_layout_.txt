Crie um layout de blog completo, moderno e responsivo para o nicho "Saúde, Longevidade e Receitas Saudáveis". 

O blog terá dois pilares visuais:
1. RECEITAS: cores quentes (laranja, terracota, amarelo)
2. BEM-ESTAR & LONGEVIDADE: cores frias (verde, azul, branco)

Páginas: Home, Artigo, Categoria, Sobre, Contato.

Diretrizes Visuais:
- Fonte: Inter (corpo) e Playfair Display (títulos)
- Cores: Laranja #e67e22, Verde #2ecc71, Fundo #f8f9fa, Texto #2c3e50
- Responsivo: celular, tablet e desktop

⚠️ REGRAS OBRIGATÓRIAS:

1. HTML deve ser ENTREGUE EM UM ÚNICO ARQUIVO com todas as páginas separadas por comentários:
   <!-- ===== PAGINA: HOME ===== -->
   <!-- ===== PAGINA: ARTIGO ===== -->
   <!-- ===== PAGINA: CATEGORIA ===== -->
   <!-- ===== PAGINA: SOBRE ===== -->
   <!-- ===== PAGINA: CONTATO ===== -->

2. CADA PÁGINA deve ter sua estrutura COMPLETA (html, head, body) para que possamos extrair cada template.

3. Use ESTES MARCADORES EXATOS (copie e cole):
   {{HEADER}} {{FOOTER}} {{LISTA_CARDS}} {{RELACIONADOS_SIDEBAR}} {{CATEGORIAS_SIDEBAR}} {{TAGS}} {{NAVEGACAO}} {{PRIMEIRO_ARTIGO}} {{HERO_TITULO}} {{HERO_SUBTITULO}} {{HERO_DESCRICAO}} {{TITULO}} {{DESCRICAO}} {{AUTOR}} {{DATA}} {{TEMPO_LEITURA}} {{IMAGEM}} {{CONTEUDO}} {{RELACIONADOS}} {{CATEGORIA}} {{DESCRICAO_CATEGORIA}} {{ARTIGOS_CATEGORIA}}

4. O CSS deve ser ENTREGUE EM UM ARQUIVO SEPARADO (style.css) com todas as regras de estilo.

5. O JavaScript deve ser ENTREGUE EM UM ARQUIVO SEPARADO (script.js) com:
   - Menu mobile (hambúrguer)
   - Scroll effect no header
   - FAQ toggle (accordion)
   - TOC (sumário) gerado automaticamente pelos headings

6. COMENTE cada seção com:
   <!-- INICIO: HEADER -->
   <!-- FIM: HEADER -->
   <!-- INICIO: HERO -->
   <!-- FIM: HERO -->
   <!-- INICIO: CONTEUDO -->
   <!-- FIM: CONTEUDO -->
   <!-- INICIO: SIDEBAR -->
   <!-- FIM: SIDEBAR -->
   <!-- INICIO: FOOTER -->
   <!-- FIM: FOOTER -->

7. As CLASSES CSS devem ser consistentes em todas as páginas:
   - Cards: .card, .card-media, .card-body, .card-title, .card-excerpt, .card-link
   - Badges: .badge, .badge--recipe, .badge--wellness
   - Grid: .grid, .grid--3
   - Sidebar: .sidebar, .widget, .widget-title, .widget--newsletter
   - Newsletter: .newsletter-form, .newsletter-success
   - Article: .article-header, .article-cover, .article-body, .article-meta, .article-share, .article-cta
   - Category: .category-header, .category-title, .category-desc, .category-grid
   - Pagination: .pagination, .page-link

8. O HEADER deve ter:
   - Logo com ícone SVG
   - Menu com links: Home, Receitas, Bem-Estar, Sobre, Contato
   - Botão menu mobile (hambúrguer)

9. O FOOTER deve ter:
   - Logo
   - Descrição do blog
   - Links: Explorar (Home, Receitas, Bem-Estar)
   - Links: Institucional (Sobre, Contato, Privacidade, Cookies)
   - Redes sociais (Instagram, YouTube, Facebook)
   - Copyright

10. O HERO deve ter:
    - Eyebrow (texto pequeno em cima)
    - Título principal com destaque
    - Descrição
    - Dois CTAs: "Ver receitas →" e "Explorar bem-estar →"

11. Os CARDS devem ter:
    - Imagem (16:9) com badge da categoria
    - Data e tempo de leitura
    - Título (link)
    - Excerto (resumo)
    - Link "Ler mais →"

12. A SIDEBAR deve ter:
    - Widget "Posts relacionados" com 3-4 itens
    - Widget "Newsletter" com formulário
    - Widget "Categorias" com lista

13. O ARTIGO deve ter:
    - Header com título, descrição, metadados (autor, data, tempo)
    - Imagem de destaque (16:9)
    - Conteúdo (texto com h2, h3, p, ul, table)
    - Compartilhar (WhatsApp, Facebook, Twitter)
    - CTA Newsletter
    - Artigos relacionados (3 cards)

14. A CATEGORIA deve ter:
    - Header com título e descrição
    - Grid de cards (4 colunas)

15. SOBRE deve ter:
    - Header com título e subtítulo
    - Grid: texto (2/3) + sidebar (1/3)
    - Valores com ícones

16. CONTATO deve ter:
    - Header com título e subtítulo
    - Grid: formulário (2/3) + informações (1/3)

OBSERVAÇÃO: O design deve ser limpo, moderno e inspirado em grandes blogs de saúde (Healthline, Bon Appétit, Tastemade). FOCO em legibilidade e experiência do usuário.
